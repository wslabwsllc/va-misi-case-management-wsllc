# Change-implementation record

Required by RFQ E.3 for the Government-provided requirement change (assumption G1, plan E1-S9). Fill in one section
per change. Implement the change in separate commits on a branch merged with a merge commit (no squash or rebase).

## Change 1: _title_

| Field | Value |
|---|---|
| Received | _date and time (ET), from whom_ |
| Change as received | _verbatim text_ |
| Clarifying questions and answers | _questions asked, answers, and the assumptions adopted (add rows to the Assumptions Log)_ |
| Principal components affected | _projects, files, migrations, ADRs, UI pages_ |
| Commits | _SHA - one-line summary, one row per commit_ |
| Tests used to validate | _new and changed tests by name, plus the full regression run_ |
| Full regression run | _`docker compose run --rm tests` result: run ID, pass/fail counts per project, revision_ |
| Contributors | _names, as in [contributor-declaration.md](contributor-declaration.md)_ |
| Documents updated | _README, ADRs, Assumptions Log, versions.md, accessibility review_ |
| Known limitations | _what the change does not cover_ |
